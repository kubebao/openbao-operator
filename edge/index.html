OpenBao Operator Edge

This directory is updated on successful CI runs for main.

  • latest/install.yaml
  • latest/crds.yaml
  • latest/checksums.txt
  • latest/checksums.txt.bundle
  • latest/provenance-index.json
  • latest/metadata.json

Helm charts: oci://ghcr.io/kubebao/charts-edge/openbao-operator. Use the chart version or digest in metadata.json.

The migration CLI is in the verified Actions bundle linked from metadata.json. The bundle requires GitHub authentication and is retained for seven days. Use one commit's CLI, chart, and images together.

See the edge installation instructions.

To install the manifest: kubectl apply -f latest/install.yaml
