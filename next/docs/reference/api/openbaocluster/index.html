AuditFileStorageConfig

AuditFileStorageConfig configures the shared filesystem integration point for file audit devices.

The operator mounts the selected PVC into each OpenBao Pod. Each Pod uses a pod-specific subPath under the same PVC so all Pods can render the same audit file path while collectors can mount the PVC read-only and read per-Pod audit files from the backing directories.
